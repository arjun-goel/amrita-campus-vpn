🔀 How to Switch Between Home Network & College Wi-Fi (Testing & Daily Use)

Step 1

Load the Browser Extension

  1. Open Chrome, Edge, or Brave and go to chrome://extensions.
  2. Turn ON Developer mode (top-right toggle).
  3. Click Load unpacked and select the extension folder inside Amrita_VPN.
Step 2

When on College Wi-Fi (Hosteller Mode)

  1. Connect your laptop Wi-Fi to the Amrita Campus Wi-Fi / LAN.
  2. Make sure the extension toggle is OFF on the Hosteller laptop (since the Hosteller is already directly on campus Wi-Fi).
  3. Double-click Start-Hosteller-Relay.bat or run:
    npm run hosteller
  4. Share the generated Session Code (e.g., AMR-4F9A) with the Day Scholar (or click Approve on their request).
Step 3

When Outside College (Day Scholar Mode)

  1. Stay connected to your Home Wi-Fi or Mobile Hotspot.
  2. Click the Amrita Campus VPN extension icon in your browser toolbar.
  3. Request access (or enter the Session Code) and click Connect Campus VPN.
  4. Open any *.amrita.edu website — it routes through the Hosteller's campus Wi-Fi while all other websites use your fast home internet!
