🖥️ How Students Use the 1-Click Desktop GUI Apps (Zero Terminal!)

Day Scholar (At Home)

1. Request & Turn ON Extension

  1. Open the Day Scholar Portal tab and submit a request for 15, 30, or 60 minutes.
  2. Click ⬇️ Download Day Scholar Desktop App and double-click the downloaded file — a Desktop GUI window opens!
  3. Click the Amrita Campus VPN Chrome Extension icon and press the ⏻ Power Button.
  4. Open aums.amrita.edu or any college portal and log in privately!
Hosteller (In Hostel)

2. Approve & Run 1-Click App

  1. Stay connected to Amrita College Wi-Fi.
  2. Open the Hosteller Portal tab and click ⬇️ Approve & Download GUI App next to the Day Scholar's request.
  3. Double-click the downloaded file (if Windows SmartScreen asks, click More info → Run anyway).
  4. A Desktop GUI App window opens with a live countdown timer! It closes automatically when the timer hits 00:00, or you can click 🛑 STOP SHARING anytime.
